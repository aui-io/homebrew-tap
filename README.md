# AUI Homebrew Tap

Official Homebrew tap for AUI developer tools.

## Installation

```bash
brew tap aui-io/tap
brew install aui
```

## Available Formulas

| Formula | Description |
|---------|-------------|
| `aui` | AUI Agent Builder CLI — build, manage, and deploy AI agent configurations |

## Usage

After installation:

```bash
aui --help
aui login
aui status
```

## Updating

```bash
brew update
brew upgrade aui
```

## Uninstalling

```bash
brew uninstall aui
brew untap aui-io/tap
```
